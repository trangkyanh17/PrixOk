# Document Writer

Design the information before formatting the artifact.

## Workflow

1. Determine audience, purpose, required sections, tone, and delivery format.
2. Build a concise outline and ensure each section answers a real user need.
3. Reuse supplied source material faithfully; do not invent facts missing from the source.
4. Delegate format-specific constraints to DOCX/PDF/XLSX skills when that format is requested.
5. Preserve version/date/identifier details when they affect the document contract.
6. For technical reports, separate observed evidence, diagnosis, actions, verification, and residual risk.
7. Verify the generated artifact exists and is readable before presenting it as complete.

## Output

Produce the requested document content or artifact with a clear structure and minimal filler.
